# ⚡ Build & Ship Your Own AI Side Panel Chrome Extension in Under 10 Minutes!

Tired of wrestling with **Chrome Manifest V3**, broken **iFrame CSP / Anti-framebusting policies**, losing **User Activation Tokens**, or struggling with **CSS conflicts** on target websites?

**OmniAI** is a battle-tested, production-ready Chrome Extension template designed to help you launch high-performance AI sidebars (like Sider, Monica, or ChatHub) with **ZERO server costs** and **100% Local-First privacy**.

---

### 🔥 What Makes This Boilerplate Special?

#### 1. 🛡️ True Zero-Reload & Keep-Alive iFrame Architecture
Most extensions reload their iframe whenever a user switches tabs, killing the active chat session. OmniAI keeps iframes alive in the DOM — switching between ChatGPT, Claude, Gemini, DeepSeek, and Google Translate happens in **0ms with zero network reload**.

#### 2. 🚀 Native Side Panel API + User Activation Guard
Built on Chrome's latest `chrome.sidePanel` API with seamless hotkey support (`Alt+S`, `Alt+Z`, `Alt+Q`). Eliminates double-call conflicts and preserves user activation tokens across all Chromium browsers.

#### 3. 🧩 Shadow DOM Isolation (`mode: 'open'`)
Your floating widgets and HUDs will **NEVER break the host webpage’s CSS**, and the host website’s stylesheets will never break your UI.

#### 4. 🔓 DeclarativeNetRequest Header Stripper
Pre-configured ruleset that safely strips `X-Frame-Options` and `Content-Security-Policy: frame-ancestors` headers, allowing seamless embedding of top AI web interfaces.

#### 5. 🎯 Smart Spotlight HUD & Context Grabber
Built-in text selection extractor, metadata parser (URL, Title, Language), token estimator, and smart clipboard fallback.

---

### 📦 What You Get Inside:

- ✅ **Full TypeScript Source Code** (React 18 + Vite 5 + CRXJS).
- ✅ **Pre-configured Providers**: ChatGPT, Claude, Gemini, DeepSeek, Qwen, Google Translate.

**Q: Can I publish extensions built with this to the Chrome Web Store?**
